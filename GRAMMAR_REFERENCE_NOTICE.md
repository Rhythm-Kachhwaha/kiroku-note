# Grammar Reference Data Notice

The bundled `backend/app/data/grammar_reference.sqlite` is generated by
`tools/build_grammar_index.py` from the checked-in grammar seed in
`jlpt_reference.sqlite` plus the checked-in OpenJLPT CSV grammar seed in
`backend/app/data/openjlpt_grammar/`.

OpenJLPT contains 123 N5, 123 N4, 101 N3, 98 N2, and 81 N1 grammar rows
in its CSV release. Its repository licence is **CC BY-SA 4.0** and it is
available at <https://github.com/evanclan/OpenJLPT>. The previously
referenced Tanos/Kotobase pages were not imported because their redistribution
terms and complete machine-readable counts could not be verified in this
environment. No unverified Tanos rows are added by the build.

Example sentences are retained as supplied by the checked-in seeds. Where
applicable, their upstream attribution is Tatoeba (**CC BY 2.0 FR**,
<https://tatoeba.org/>).

This notice and the build script are included so the SQLite artifact can be
reproduced from repository data without network access.
