# Grammar Reference Data Notice

The bundled `backend/app/data/grammar_reference.sqlite` is generated by
`tools/build_grammar_index.py` from the checked-in grammar seed in
`jlpt_reference.sqlite`.

The grammar seed is derived from Jonathan Waller's Tanos JLPT grammar list
(Kotobase, **CC BY 4.0**) and OpenJLPT (**CC BY-SA 4.0**). OpenJLPT is
available at <https://github.com/evanclan/OpenJLPT>; Tanos resources are at
<https://www.tanos.co.uk/jlpt/>. Example sentences are retained as supplied
by the seed; where applicable their upstream attribution is Tatoeba
(**CC BY 2.0 FR**, <https://tatoeba.org/>).

This notice and the build script are included so the SQLite artifact can be
reproduced from repository data without network access.
