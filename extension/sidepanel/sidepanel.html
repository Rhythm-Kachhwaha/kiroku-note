Quick Setup Guide

  1. Backend: Start backend service (python run_backend.py on port 21828)
  2. Yomitan: Install Yomitan extension and import your Japanese dictionaries
  3. Anki: Open Anki with AnkiConnect installed (port 8765)
  4. Start Mining: Click Start to begin capturing words
