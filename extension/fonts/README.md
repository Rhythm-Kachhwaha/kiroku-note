# Kiroku Note — Extension Fonts

This directory is reserved for offline local font assets (e.g. WOFF2) for Japanese typography.
The extension sidepanel utilizes `@font-face` declarations with local system font fallbacks (Noto Sans JP, Hiragino Sans, Yu Gothic, Meiryo, Yu Mincho) and a strict Content Security Policy that disallows external network requests to third-party font CDNs.
